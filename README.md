# 전국 학과 지도

**전국 대학의 학과를 갈래로 묶어 보는 진학 상담 도구입니다.**

「컴퓨터공학과에 가고 싶어요」라는 학생에게
**「이름은 달라도 같은 갈래인 학과가 이만큼 있다」**를 보여 주는 것이 목적입니다.

전국 **408개 대학·캠퍼스**의 학부 학과 **16,221개**가 담겨 있습니다.

👉 **바로 쓰기 — https://trmoo.github.io/major-map/**

내려받아 쓰려면 `dist/index.html` 한 파일만 있으면 됩니다. **인터넷 없이 더블클릭으로 열립니다.**

## 무엇을 할 수 있나

| 탭 | 하는 일 |
|---|---|
| 🗺️ **계열 지도** | 큰 갈래 6 → 중간 갈래 28 → 작은 갈래 160 으로 파고들며 봅니다 |
| 🔎 **학과 찾기** | 이름 하나를 넣으면 **같은 갈래인데 이름이 다른 학과**를 전부 보여 줍니다 |
| 📍 **위치 지도** | 학과를 고르면 **전국 어느 대학에 있는지 지도**에 찍습니다. 수도권은 확대 지도로 따로, 점을 누르면 그곳 대학 목록 |
| 🔤 **이름 비교** | 「간호학과 / 간호학부 / 간호전공 / 간호대학」처럼 갈린 이름을 한 줄로 모읍니다 |
| 🏫 **대학별 보기** | 대학 하나의 개설 학과 전부와 계열 분포 |
| 📖 **안내** | 자료 출처 · 표준분류 전체 · 이 앱이 못 하는 것 |

### 「유사 학과」를 잇는 두 가지 방법

**섞지 않고 따로 보여 줍니다.** 어느 근거인지 모르면 잘못 믿게 되기 때문입니다.

1. **표준분류계열** — 교육부가 학과마다 매겨 공시한 분류입니다. **우리가 지어낸 것이 아닙니다.**
2. **이름 열쇠** — 괄호와 「학과·학부·전공」 꼬리를 떼고 어간이 같은 것을 모읍니다. 어림입니다.

둘 다 「같다」고 한 학과는 **🎯 거의 확실히 같은 학과**로 맨 위에 따로 보여 줍니다.

### 학과 위치 지도

* 기준을 셋 중에서 고릅니다 — **이 이름 그대로 / 이름이 비슷한 학과 / 같은 표준분류(소)**.
  단추마다 대학 수가 적혀 있어 「넓히면 이만큼 는다」가 보입니다.
* 위치는 대학 본부가 아니라 **그 학과가 있는 캠퍼스**의 시·군·구입니다
  (캠퍼스가 서울과 수원에 있는 대학은 학과마다 다른 곳에 찍힙니다).
* **점은 캠퍼스의 정확한 위치가 아니라 시·군·구의 대표 위치**입니다.
* 원격대학(사이버·방송통신)은 기본으로 뺐습니다. 켜면 들어옵니다.
* 주소를 그대로 알려 주면 같은 지도가 열립니다 — 예: `#wichi/hakgwa?q=간호학과&by=so`

## ⚠ 먼저 알아 두실 것

* **합격 가능성을 말하지 않습니다.** 입결·경쟁률 자료가 들어 있지 않습니다.
* **학과명은 「모집단위」가 아닙니다.** 실제로 뽑는 단위는 「인문계열」·「자유전공학부」처럼
  여러 학과를 묶은 이름일 때가 많습니다. **지원 전에는 모집요강을 확인하세요.**
* **분류가 없는 학과가 약 12%** 있습니다(자율전공·광역모집). 억지로 채우지 않았습니다.
* **대학원은 뺐습니다.** 고교 진학 상담용이라 학부만 담았습니다.

## 개발자용

```bash
npm install
npm run dev          # 개발 서버 (http://localhost:5173)
npm test             # 시험 101가지
npm run check:syntax # 소스 전수 문법·규칙 검사
npm run build        # dist/index.html 한 파일로 빌드
```

자료를 새로 받았을 때:

```bash
npm run data         # source/ → src/data/major.json + map.json
```

지도를 다시 만들려면 [southkorea-maps](https://github.com/southkorea/southkorea-maps) 의
`kostat/2013/json/skorea_provinces_geo.json` 을 `source/kostat2013_provinces-geo.json` 으로 두세요.

파이썬과 `openpyxl` 이 필요합니다. 원본 엑셀은 [공공데이터포털](https://www.data.go.kr/data/15119002/fileData.do)
에서 내려받아 `source/키워드별 학과정보.xlsx` 로 두세요. (`source/` 는 저장소에 올리지 않습니다)

자세한 개발 기록은 [`CLAUDE.md`](CLAUDE.md) 에 있습니다.
